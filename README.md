🌿Sistema de Controle de Plantas
Autora: Valérya Abygail Rocha de Assis

TEMA DO PROJETO
Este projeto tem como objetivo controlar e organizar os cuidados com as plantas de um jardim. O sistema permite o cadastro de informações como nome da planta, tipo de planta e frequência de rega. Além disso, ele oferece alertas para lembrar o usuário quando uma planta precisa ser regada.

O QUE ELE DEVE FAZER 
Cadastrar plantas comuns e plantas de interior.

Armazenar os dados em um banco de dados (SQLite).

Exibir informações detalhadas das plantas cadastradas.

Permitir excluir plantas do sistema.

Verificar se alguma planta está há muitos dias sem regar.

QUAL SERÁ A ESTRUTURÁ DA INTERFACE
O sistema possui uma interface simples de texto (no terminal), com um menu interativo para o usuário escolher as opções.
No futuro, ele pode ser expandido para uma interface gráfica.

PERGUNTAS
QUAIS TELAS MEU SISTEMA PRECISA?
Menu principal: onde o usuário escolhe o que deseja fazer (cadastrar, listar, excluir ou sair).

Tela de cadastro de planta comum: onde o usuário informa nome, tipo e frequência de rega.

Tela de cadastro de planta de interior: além dos campos anteriores, também é solicitado o local da casa.

Tela de listagem de plantas: exibe todas as plantas cadastradas e seus dados.

Tela de exclusão de planta: permite deletar uma planta informando o nome.

QUE CAMPOS DEVEM APARECER NO FORMULÁRIO?
Nome da planta

Tipo da planta (ex: flor, erva, folhagem)

Frequência de rega (em dias)

Local da casa (apenas para plantas de interior)

COMO O USUÁRIO VAI INTERAGIR COM MEU SISTEMA? 
O usuário irá interagir por meio do teclado, utilizando o menu exibido no terminal.
Ele digita o número da opção desejada e preenche os campos solicitados quando for cadastrar uma planta.
O sistema responde com mensagens de confirmação, listagens e alertas simples.
